# 朋意除湿袋实训网店页面

本页面用于课程实训，商品参数、价格、订单和售后均为模拟数据，不发生真实付款或发货。

当前版本包含三档规格选择、购物车、模拟下单、成交确认单、订单档案、订单搜索、CSV台账导出、交互式吸湿进度演示和移动端购买栏。

## 打开方式

解压后双击 `dist/index.html` 即可在浏览器中打开。页面包含商品详情、规格说明、常见问题、模拟下单和可打印成交确认单。

## 修改位置

- 页面文字与结构：`dist/index.html`
- 颜色与排版：`dist/styles.css`
- 模拟订单逻辑：`dist/app.js`

正式经营前，请把规格、价格、成分、净含量、执行标准、安全提示、运费和售后政策替换为经项目组核实的信息。
